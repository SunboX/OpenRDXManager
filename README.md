# OpenRDXManager

An Electron desktop application for managing RDX drives and removable cartridges
on Windows, macOS, and Linux.

The project combines a JavaScript interface with a native Rust service for device
access. Its management areas cover device status, encryption, diagnostics, and
utilities.

Development is ongoing. Available operations and hardware compatibility depend
on the platform and connected device.

This repository currently contains this introductory README. Project source code
will be added later.
