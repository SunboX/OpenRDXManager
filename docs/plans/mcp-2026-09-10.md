# MCP integration implementation plan — 2026-09-10

Historical plan. This records the requirements and approach at the stated date; it does not establish current completion or hardware acceptance. See [verification](../verification/README.md) for recorded results.

**Goal:** Let local AI clients read every public value and operate every supported application capability through MCP.

**Architecture:** An authenticated loopback HTTP endpoint owns no device runtime; it dispatches through the same services as Electron IPC. A stdio bridge attaches to that endpoint. Public operation history consumes accepted coordinator events.

**Tech stack:** Native ESM, Node >=22.12, Electron, Zod 4, official MCP SDK v2, Node test runner.

**Spec:** `docs/specs/mcp-2026-09-10.md`

## Constraints

- Preserve all pre-existing modifications; no staging or commits of unrelated work.
- Keep renderer sandbox defaults and main-only privileged access.
- Retain native capability, revision, confirmation, cancellation and shutdown checks.
- Keep added/modified handwritten modules below 1,000 lines; extract cohesive helpers where needed.
- Test hardware mutations using controlled services; runtime acceptance is read-only.
- Use `/Users/afiedler/.nvm/versions/node/v22.16.0/bin` first on PATH for commands.
